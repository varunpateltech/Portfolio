# Varun Patel, Portfolio Website

Personal portfolio website for [buildwithvarun.com](https://buildwithvarun.com).

## About

A single-page portfolio showcasing my product management career spanning 14+ years in IoT, connectivity platforms, satellite, and enterprise SaaS across Africa, Asia, and Europe. Includes my experience timeline, product case studies, certifications, media appearances, and testimonials.

## Tech Stack

- Pure HTML, CSS, and JavaScript (no build tools required)
- Google Fonts (Playfair Display + Source Sans 3)
- Hosted on Netlify with custom domain

## Local Development

Simply open `index.html` in your browser. No server or build step needed.

## Deployment

This site auto-deploys to Netlify on every push to the `main` branch.

## Structure

```
index.html                ← The entire portfolio (single-file site)
Varun_Patel_Resume.pdf    ← Linked resume download
Images/                   ← Photos used in the gallery and media sections
Certifications/           ← Certificate PDFs backing the Certifications section
assets/                   ← Reserved for future CSS/JS extraction (currently empty)
docs/                     ← Reserved for additional documentation (currently empty)
CLAUDE.md                 ← Project guidance for AI-assisted edits
README.md                 ← This file
```
